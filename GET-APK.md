## 🚀 How to Build Your APK (4 Easy Methods)

### **METHOD 1: GitHub Actions (Automatic) ⭐ EASIEST**

**Step 1:** Go to GitHub Actions
```
https://github.com/SN1502/file-viewer-app/actions
```

**Step 2:** Look for "Build APK" workflow on the left side

**Step 3:** Click on the latest run (or "Run workflow" to trigger new build)

**Step 4:** Wait 15-20 minutes for build to complete

**Step 5:** Download APK from "Artifacts" section

✅ **No setup needed**
✅ **Automatic on every push**
✅ **Free**

---

### **METHOD 2: Using Expo (Fast Cloud Build) ⭐⭐**

**Step 1:** Install EAS CLI
```bash
npm install -g eas-cli
```

**Step 2:** Create free Expo account
```bash
eas login
```

**Step 3:** Build APK in cloud (no Android SDK needed!)
```bash
eas build --platform android --non-interactive
```

**Step 4:** Wait 10-15 minutes

**Step 5:** Download from Expo dashboard or email

✅ **Cloud builds - faster**
✅ **Professional signing**
✅ **Play Store ready**

---

### **METHOD 3: Capgo Online Builder (Fastest) ⭐⭐⭐**

**Step 1:** Go to https://capgo.app/app-build

**Step 2:** Upload your `dist/` folder files

**Step 3:** Set app name to "File Viewer"

**Step 4:** Click "Build APK"

**Step 5:** Wait 5-10 minutes

**Step 6:** Download APK

✅ **No command line needed**
✅ **Fastest option**
✅ **Web-based UI**

---

### **METHOD 4: Local Build (Advanced)**

Requires Android SDK (10+ GB download):

```bash
# Setup (one time)
# Download: Android SDK, NDK, Java JDK

cd android
./gradlew assembleRelease

# APK at: android/app/build/outputs/apk/release/
```

✅ **Most control**
✅ **For developers**
❌ **Complex setup**
